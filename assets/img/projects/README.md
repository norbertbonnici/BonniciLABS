# Project images

Drop a project's photo / screenshot / icon here, then point to it from the
project's front matter:

```yaml
image: /assets/img/projects/my-project.jpg
image_alt: "Short description of the picture"
```

Square images look best (they're shown beside the title). PNG, JPG, SVG or
WebP all work. The three `.svg` files here are placeholder icons for the apps —
replace them with the real thing.

Any project without an `image:` automatically shows a monogram tile instead,
so the layout never breaks.
