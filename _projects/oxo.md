OxO is a minimal 3D Tic-tac-toe game where both players can place both X’s and O’s. 

The goal is to get a set of O’s or X’s in any direction (vertical, horizontal, diagonal and across the grids). 

OxO is currently available on the Windows Store for Windows 8, 8.1, 10 running x86, x64, ARM 

Download on the [Windows App Store](https://www.microsoft.com/en-us/p/oxo/9wzdncrdcl7p)
